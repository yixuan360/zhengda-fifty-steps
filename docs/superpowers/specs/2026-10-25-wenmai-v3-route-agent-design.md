> 状态：待负责人确认

## 一、一句话定位

**把 105 个孤立景点，编排成一条会随你的时间、兴趣和现场情况调整的校园叙事路线。**

不是“导览 App + 问答框”，而是“会规划、会连接、会调整的校园文脉导演”。

## 二、两条路线

|---|---|---|---|
| 1 | 河源（id=6） | 黄河之水、文明起源 | 90s |
| 2 | 问鼎（id=7） | 商代青铜、问鼎中原 | 75s |
| 3 | 博弈（id=8） | 楚河汉界、荥阳鸿沟 | 75s |
| 4 | 禅趣（id=9） | 少林禅宗、渡学海 | 75s |
| 5 | 观星测影（id=11） | 登封观星台、科学精神 | 90s |
| 6 | 大道通衢（id=12） | 铁路枢纽、郑州交通史 | 75s |
| 7 | 凤台荷香（id=13） | 清代郑州八景、园林审美 | 75s |

- 顺序：南 → 北，沿眉湖展开；
- 完整版：8 站，约 35–40 分钟；
- **主 demo**：7 站（河源、问鼎、博弈、禅趣、观星测影、大道通衢、凤台荷香），约 30–35 分钟；
- **可选延伸**：杏坛槐林，+8–10 分钟；Agent 会说明“完整线 8 站，今天走 7 站，杏坛槐林留到下次”；
- 主题弧（7 站）：水 → 青铜 → 楚汉 → 禅 → 天文 → 铁路 → 荷香；杏坛槐林（书院）作为可选延伸。

### 路线二：中轴三章 · 入门线

**从南门到钟楼，一所大学的空间秩序**

| # | 点位 | 章节 | 建议时长 |
|---|---|---|---|
| 1 | 南大门（id=1） | 入口：一进一出 | 90s |

| 3 | 钟楼（id=16） | 中心：时间与认同 | 120s |

- 顺序：南 → 北，沿中轴；
- 核心版：3 站，约 20–25 分钟；
- 扩展版：加五星广场（id=2）、校史馆（id=4）、元和广场（id=15），约 30–35 分钟；
- 主题：入口 → 治理 → 时间/中心；
- **角色**：备选/另一条线；demo 结尾推荐，不作为主演示。

## 三、核心交互

1. **入口**：首页/地图上的“带我走”按钮。
2. **规划**：底部弹层选时间（20/30/45 分钟）、兴趣（建筑/校史/自然/随便走走）、起点（当前位置/南大门/眉湖）。
3. **路线卡**：线路名、副标题、总时长、步行距离、站点列表。
4. **走线**：
   - 到点自动播固定音频；
   - 播完播 20–30 秒过渡；
   - 可点“深入一点”进入单点深度稿；
   - 可点“下一站 / 时间不够了 / 下雨了 / 想多待一会”。
5. **收尾**：今天走了几个点、听了几个故事、分享卡。

```
┌─────────────────────────────┐
│ 眉湖八景 · 水脉线            │
│ 从河源到凤台荷香，30–35 分钟  │
│ 7 站 · 步行约 0.9 km         │
│                             │
│ ① 河源         ⑤ 观星测影    │
```

> 完整线有 8 站；这张卡是 Agent 按 30 分钟走 7 站，杏坛槐林留到下次。

## 四、Agent 行为

| 能力 | 规则 |
|---|---|
| 选线 | 时间 <30 分钟 → 中轴；30–45 分钟 → 眉湖短版或中轴扩展；>45 分钟 → 眉湖完整版 |
| 兴趣 | 建筑/校史 → 中轴；自然/文明 → 眉湖；随便走走 → 按距离和时长 |
| 裁剪 | 时间不够：先删可选站，再删过渡，最后缩短单点 |
| 加站 | 时间富余：加五星广场/校史馆/元和广场，或眉湖北段 |
| 现场调整 | “时间不够了”缩短；“下雨了”改到最近室内收尾；“想多待一会”加深度稿 |
| 记忆 | 记住已走站点、已听内容、已问问题，避免重复 |
| 核验 | 过渡和回答只使用已审内容/已核资料；带来源；不编 |
| 缺口 | 答不上就记缺口，推荐相关站点，不硬答 |
| 降级 | Agent 服务不可用 → 预置路线卡 + 固定音频，不白屏 |

## 五、内容清单

### 已具备

- 钟楼：建筑、活动 2 篇深度稿；
- 图书馆：建筑、历史 2 篇；
- 计算机学院：学科、历史 2 篇。

### 需要新增（比赛版）

- **眉湖八景（主 demo，优先）**：河源、问鼎、博弈、禅趣、观星测影、大道通衢、凤台荷香各 1 篇 300–400 字；7 站过渡 6 段优先；杏坛槐林作为可选延伸，后置；
- **中轴三章（备选，可后置）**：南大门 1 篇、综合中心 1 篇（600 字左右，带来源）；
- 两线共需：路线开场 2 段、过渡段 8–10 段、收尾 2 段（每段 20–30 秒）。

### 内容原则

- 沿用“检索核对 → 小骨架 → 写解读 → 核验 → 人审”；
- 关键事实标注来源；冲突标注口径；
- 过渡段不重复点位介绍，只负责“连接”。

## 六、3 分钟 Demo 脚本

| 时间 | 画面 | 说明 |
|---|---|---|
| 0:00–0:20 | 打开 App，点“带我走” | 选 30 分钟、自然+文明、眉湖 |
| 0:20–0:40 | Agent 生成“眉湖八景·水脉线” | 7 站、约 0.9 km、30–35 分钟；说明完整线 8 站，今天走 7 站，杏坛槐林留到下次 |
| 0:40–1:20 | 河源固定音频 → 过渡到问鼎 | 过渡讲“从黄河之水到商代青铜” |
| 1:20–1:50 | 问鼎固定音频 → 点“深入一点” | 展示鼎、商代、问鼎中原的深度稿 |
| 1:50–2:20 | 跳到观星测影/大道通衢 | 展示“从古代天文到现代铁路”的过渡；用户提问，Agent 带引用回答 |
| 2:20–2:40 | 用户点“下雨了” | Agent 改到眉湖小屋收尾，凤台荷香之后不再北上 |
| 2:40–3:00 | 收尾卡 + “中轴三章”推荐 | 展示另一条线，结束 |

> 3 分钟演示不必逐站走完：路线卡展示 7 站，现场只演河源、问鼎、观星测影/大道通衢 3–4 个关键站。  
> 可选加演：问一个未收录问题（如“问鼎的鼎是谁设计的？”），Agent 回答“暂未收录”并记缺口，展示 Agent 的诚实与生长闭环。

## 七、比赛版范围

### Must

- 两条路线元数据 + **眉湖 7 个核心点（主 demo）** + 中轴 3 站（备选）；杏坛槐林作为可选延伸；
- “带我走”入口 + 路线卡 + 固定音频 + 过渡段；
- 3 个现场调整按钮；
- 眉湖核心点深度稿（问鼎/观星测影至少 1 篇可加深）；钟楼深度稿保留为备选；
- 失败降级到固定播报。

### Should

- 每站后“继续问”一次（不做多轮）；
- 缺口记录；
- 结束小结/分享卡。

### Won't

- 105 个景点全覆盖；
- 自动天气/人流/GPS 实时重排（先用按钮）；
- 自由多轮问答；
- iOS 版本。

## 八、验收标准

1. 选时间/兴趣后，3 秒内出路线卡；
2. 路线卡上的站点、时长、距离与实际一致；
3. 到点固定音频可播，过渡段可播；
4. 三个调整按钮都能改变路线，并有可见反馈；
5. Agent 服务不可用时，仍能按预置路线演示；
6. 原版 `main` / V1 不受影响；
7. 3 分钟 demo 能完整走完。

## 十、默认决定（可调整）

- 主 demo 路线：**眉湖八景**；
- 眉湖八景：主 demo 走 7 站（河源→问鼎→博弈→禅趣→观星测影→大道通衢→凤台荷香）；杏坛槐林作为可选延伸/下次再来；
