## 二、开发环境启动

### 2.1 后端（Django）

```bash
# 1. 激活 conda 环境
conda activate zhengda-backend

# 2. 安装依赖
cd server
pip install -r requirements.txt

# 3. 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS zhengda DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 4. 复制并编辑环境变量
cp .env.example .env
# 编辑 .env：填入 DB_PASSWORD / SECRET_KEY

# 5. 数据库迁移
python manage.py migrate --fake-initial

# 6. 创建超级用户
python manage.py createsuperuser

# 7. 导入种子数据
python seed_spots.py

# 8. 启动开发服务器
python manage.py runserver 0.0.0.0:8000
```

Django Admin 访问：`http://localhost:8000/manage/`

### 2.2 前端（Expo）

```bash
# 1. 安装依赖（postinstall 自动重放 RNTP 新架构补丁）
cd app
npm install

# 2. 复制并编辑环境变量
cp .env.example .env
# 编辑 .env：填入 EXPO_PUBLIC_API_BASE_URL / EXPO_PUBLIC_AMAP_API_KEY

# 3. 启动 Expo 开发服务器
npx expo start
```

## 三、生产环境部署

### 3.1 后端部署（ECS + Nginx + Gunicorn）

```bash
# 1. SSH 到 ECS，拉代码
cd /var/www
git clone <repo-url> zhengda-fifty-steps
cd zhengda-fifty-steps/server

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置 .env（生产值）
# DEBUG=False
# ALLOWED_HOSTS=api.zhengda.com
# DB_PASSWORD=<生产密码>
# SECRET_KEY=<随机字符串>
# ADMIN_URL=manage/
# CORS_ALLOWED_ORIGINS=https://app.zhengda.com
# CSRF_TRUSTED_ORIGINS=https://api.zhengda.com

# 4. 数据库迁移
python manage.py migrate --fake-initial
python manage.py collectstatic --noinput

# 5. 创建 systemd 服务
sudo tee /etc/systemd/system/gunicorn-zhengda.service << 'EOF'
[Unit]
Description=Zhengda Gunicorn
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/zhengda-fifty-steps/server
ExecStart=/home/admin/anaconda3/envs/zhengda-backend/bin/gunicorn config.wsgi:application \
    --bind 127.0.0.1:8000 \
    --workers 4 \
    --timeout 120
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now gunicorn-zhengda
```

### 3.2 Nginx 配置

```nginx
# /etc/nginx/sites-available/zhengda
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=10r/s;

server {
    listen 443 ssl;
    server_name api.zhengda.com;

    ssl_certificate     /etc/ssl/certs/zhengda.pem;
    ssl_certificate_key /etc/ssl/private/zhengda.key;

    client_max_body_size 50m;

    # 静态媒体文件（Admin 上传的图片/音频）
    location /media/ {
        alias /var/www/zhengda-fifty-steps/server/media/;
        expires 30d;
    }

    # 静态文件（Django Admin 的 CSS/JS）
    location /static/ {
        alias /var/www/zhengda-fifty-steps/server/staticfiles/;
        expires 7d;
    }

    # API 限流 + 代理
    location /api/ {
        limit_req zone=api_limit burst=5 nodelay;
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Admin 后台
    location /manage/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# HTTP → HTTPS 重定向
server {
    listen 80;
    server_name api.zhengda.com;
    return 301 https://$server_name$request_uri;
}
```

```bash
sudo ln -s /etc/nginx/sites-available/zhengda /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 四、环境变量清单

### Django `.env`

| 变量 | 说明 | 开发默认值 | 生产 |
|------|------|-----------|------|
| `SECRET_KEY` | Django 密钥 | 占位值 | **必须改为随机长串** |
| `DEBUG` | 调试模式 | `True` | `False` |
| `ALLOWED_HOSTS` | 允许的域名 | `localhost,127.0.0.1,10.0.2.2` | 真实域名，逗号分隔 |
| `DB_NAME` | 数据库名 | `zhengda` | 同 |
| `DB_USER` | 数据库用户 | `root` | 生产用户 |
| `DB_PASSWORD` | 数据库密码 | — | **必须填写** |
| `DB_HOST` | 数据库地址 | `localhost` | 同 |
| `DB_PORT` | 数据库端口 | `3306` | 同 |
| `ADMIN_URL` | Admin 路径 | `manage/` | 同（非默认值） |
| `WECHAT_APP_ID` | 微信 AppID | 占位值 | 真实值 |
| `WECHAT_APP_SECRET` | 微信 Secret | 占位值 | **保密** |
| `CORS_ALLOWED_ORIGINS` | CORS 白名单 | 空=全允许 | 真实域名 |
| `CSRF_TRUSTED_ORIGINS` | CSRF 可信源 | 空 | `https://api.xxx.com` |

### App `.env`

| 变量 | 说明 | 示例 |
|------|------|------|
| `EXPO_PUBLIC_API_BASE_URL` | 后端 API 地址 | `https://api.zhengda.com` |
| `EXPO_PUBLIC_AMAP_ANDROID_KEY` | 高德 Android 原生 Key（绑定包名+SHA1） | 从高德控制台获取 |
| `EXPO_PUBLIC_WECHAT_APP_ID` | 微信 AppID | V1 可用占位值 |

## 六、常见问题

### Q1: MySQL 连接被拒
确保 `.env` 中 `DB_PASSWORD` 填写正确，数据库 `zhengda` 已创建且用户有权限。

### Q2: `ModuleNotFoundError: No module named 'pymysql'`
`pip install pymysql`，已在 `config/__init__.py` 中做 monkey-patch。

### Q3: 图片/音频上传后 App 不显示
确认 `MEDIA_URL` 和 Nginx `/media/` 路径一致；生产环境 Nginx 代理 `/media/` 到 `MEDIA_ROOT`。

### Q4: Gunicorn 启动后 502
检查 `gunicorn` 路径是否和 conda 环境一致（`which gunicorn`）；确认 `--bind` 端口未被占用。

### Q5: Admin 访问 404
Admin 路径已改为 `manage/`（非默认 `admin/`），通过 `.env` 的 `ADMIN_URL` 配置。

### Q6: 测试跑不过
确认 `ALLOWED_HOSTS` 包含 `testserver`；确认 `TESTING=True` 在 pytest 中生效。

### Q7: EAS 构建报 Duplicate class（com.amap.api）
高德 3dmap 内置了定位核心类，与独立 location 包冲突。已通过两处配置解决：
- EAS 路径：`app/plugins/withExcludeAmapLocation.js` 自动注入 Gradle exclude
- 本地路径：`app/android/app/build.gradle` 末尾已有 `configurations.all { exclude }`
若重新 `expo prebuild` 生成了干净的 android/，需手动补回 build.gradle 末尾的排除配置。

### Q8: `npm install` 后 RNTP 补丁未生效
检查 `package.json` 的 `postinstall` 脚本是否包含 `patch-package`；
确认 `app/patches/react-native-track-player+4.1.2.patch` 文件存在且未损坏。
