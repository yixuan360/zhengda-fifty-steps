## 一、项目一句话

面向郑州大学学生与访客的**校园语音导览 App**：打开即地图，走进景点触发范围后自动播放语音讲解（"五十步一景，到达即播"），内容涵盖校内自然人文景观及郑大/郑州/河南历史文化。

## 二、技术栈（现行）

| 端 | 技术 |
|---|---|

| 地图/定位 | `react-native-amap3d` 3.2.4（高德 3D SDK，自定义去 POI 底图样式）+ `react-native-amap-geolocation`（GCJ-02 直出） |

## 三、数据现状

- **景点数量：105 个**（id 1~108，缺 41/82/84）：16 个 polygon + 4 个 corridor（id 42 校园商业街、79 亭云路、80 天建大道、81 碧玉桥）+ 85 个 circle。
- **数据源原则（2026-08-08 决议）：Django DB 是唯一真源**。数据流单向：`Django DB → spots_to_seed_from_json.py → app/constants/seedSpots.ts`（2026-08-21 再生成，标注 V105）。禁止直接手改 seedSpots.ts。
- 分类：architecture / humanity / nature / teaching 等（Category 表可配置）。
- 坐标全链路 GCJ-02。
- 媒体文件（图片/音频）存 `server/media/`，经 Nginx 代理下发，App 首次使用时下载缓存。
- 内容采编底稿：根目录 `信息汇总.xlsx`（2026-07-18 版，"主要地点"sheet 69 条）——**是旧版底稿**，其中坐标等已与现行数据不一致（如 id 6"河源"），一切以上游 DB 为准。
- `server/spots_dump.json` 是 **2026-07-18 旧快照（42 条、全 circle）**，已过时，详见同目录 `spots_dump.README.md`。

## 四、触发引擎（现行）

以 `app/hooks/useTour.ts` + `app/utils/trigger.ts`（v4.1）为准：

- 三种触发几何（circle / corridor / polygon）统一归一化为**有符号距离标量 d**（turf 实现，polygon 自动闭合，脏数据退化圆）；
- **纯"区域内即播"**：d ≤ 0 判为进入围栏，d > 20m（BUFFER_METERS 滞回缓冲带）判为离开；多点命中就近优先 + 队列顺位播放；
- 定位精度分级过滤（accuracy ≤ 30m 为 good，poor 连续样本抑制）；
- 冷却为**双条件**：60 秒墙钟**或**离开围栏即清除，重新进入可立即再播（2026-08-07 Task 1 修复）；
- 触发记录写入 `play_history`（SQLite）；
- **无方向/轨迹感知**：轨迹感知与方向置信度方案已于 2026-08-08 评审否决并完整删码（spec v1.3 决议 #7）；
- 回归测试：`npm run test:trigger`（`app/scripts/verify-trigger.js` 编译真实 trigger.ts 对拍种子数据）。

## 五、App 功能现状

- **地图首页**：高德地图 + GPS 蓝点 + 景点 Marker + 触发状态提示 + 精度不足横幅；自定义样式去 POI，初始视野对准主校区；
- **景点列表页**：分类浏览 + 下拉刷新；
- **景点详情页**：图文 + 音频讲解；
- **悬浮播放条 + 后台播放**（RNTP，含锁屏控制）；
- **离线兜底**：seedSpots 内置种子 + SQLite 缓存 + 媒体文件缓存，联网后全量同步覆盖；
- **登录**：微信登录**未真实对接**（accounts/views.py 留 TODO，code 冒充 openid，`WECHAT_APP_ID=wx_demo` 占位），仅 DEBUG 下 Mock 登录。

## 六、后端功能现状

- 只读 API：`GET /api/v1/spots/`（无鉴权）；
- 写 API：`POST /api/v1/spots/write/`、`PATCH/DELETE /api/v1/spots/write/<id>/`（`X-Editor-Key` 头鉴权 + 触发结构校验 + 校园坐标范围校验）；
- Django Admin：批量启用/禁用/标记音频就绪、地图选点 widget、**走廊编辑器（半宽可视化）**、trigger 结构校验；Admin 路径为 `manage/`（由 `ADMIN_URL` 配置）；
- `config` app：GlobalConfig（配置下发）、Category、DevicePing（设备活跃统计，按 device_id + 日期去重）；
- **手机端触发区域编辑器已于 2026-08-25 移除**，现行编辑器仅 Admin 端。

## 九、已知缺口与未兑现项

- 微信登录真实 code2Session 对接（桩实现在位）；
- 播放记录上报、已逛/未逛标记、收藏（用户体系深化）；
- 步行路线导航规划（V2 规划项）；
- 多语种音频、多图/多媒体（SpotMedia 子表）；
- 独立 Web 管理端、CI/CD、Sentry；
- **运行时 AI 能力为零**：edge-tts 仅是离线内容生产工具，无 LLM 接入、无问答/对话/智能交互；
- 郑州大学首届 AI 智能体创新应用大赛（`zzu_agent/`）参赛升级已在规划中，方向为"AI+校园服务与治理"。
