地图页 · 首页(tabs)/map.tsx
  • 打开 App 即进入地图（根路由 index.tsx 重定向），初始视野为郑大主校区中心（缩放 15）
  • 高德原生地图（react-native-amap3d），关闭旋转/倾斜/缩放控件，顶部为状态提示条（同步中 / 精度不足暂停 / 模拟定位黄标等）
  • 右上角触发围栏开关：绿色 15% 填充 + 45% 描边，支持圆形 / 走廊（Polyline）/ 多边形（Polygon）三种触发几何
  • 右下角回中按钮：将镜头移回用户当前位置（缩放 16）
  • 用户位置使用 JS Marker 蓝点（mock 优先），与触发引擎同一数据源，消除双定位源错位
  • 「模拟」5 连击弹出模拟定位面板；底部调试面板（坐标 / 精度 / 门控 / 最近景点 / 引擎 / 触发记录）仅 preview 构建可见
景点列表页(tabs)/list.tsx
  • 六个分类手风琴分组：学院 / 自然景观 / 特色建筑 / 教学区 / 生活服务 / 人文景观，每组左侧 4px 分类色指示条
  • 分组默认全部收起，点击标题展开；有定位时按距当前位置由近到远排序，无定位按名称拼音
  • 景点卡片（SpotCard）：左侧主色竖条 + 100×100 缩略图 + 名称 + 两行简介 + 距离胶囊（如 320m / 1.2km）
  • 下拉刷新从服务器同步；同步失败时顶部显示红色警示条（可点击演示按钮查看）
景点详情页spot/[id].tsx
  • 顶部导航：返回 + 景点名（header 底色 #F2F4F6、返回键主色）
  • 260px 大图 + 距离胶囊（距您 xxx m）+ 大标题
  • 「简介」（16px 加粗）+「详细介绍」两段式内容排版，小节标签为绿色大写字母
  • 播放/停止两态按钮：未播放为描边样式「播放语音讲解」，播放中变为实心「停止播放」（点击可切换演示）
  • 无语音导览时显示提示卡（该景点暂无语音导览 / 请连接服务器后下拉刷新）
