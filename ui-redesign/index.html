01 · 为什么需要动颜色

现状诊断

基于 theme.ts 与三个页面真实样式逐项核对，共 6 条。

D1
色彩双族并立
品牌只用单一绿 #1A7A5A，而六分类是另一组彩虹色（深红/绿/棕/青/紫/黄），界面同时出现 8+ 色相，两组颜色缺乏共同血缘。
D2
品牌绿辨识度一般
接近“通用成功绿”，与郑大 / 中原文化叙事（天地之中、眉湖八景、青铜器）绑定弱，换任何校园 App 都成立。
D3
底色偏冷
冷灰 #F2F4F6 + 88% 白卡通透但暖度低，与校园湖光、银杏、红砖等真实场景的气质略有温差。
D4
地图首屏色相冲突
打开 App 第一屏就是地图，但高德默认蓝 Marker #1B9CFC 与品牌绿打架，首屏即违和。
D5
次要文字对比不足
caption #999 在白卡上约 2.6:1，未达 WCAG AA（4.5:1）；距离胶囊的小绿字、时间戳等易读吃力。
D6
状态条文字对比不均
棕 / 黄底上的白字约 3.3:1 勉强可读；三套方案均改深字或加深底色解决。

把现有绿做深做暖，让所有颜色“长在同一棵树上”：主色加深近 40%，底色冷灰换成宣纸米，六分类色统一为低饱和同明度，去彩虹感。品牌延续性最好，改动最平滑。

  • 主色 #1A7A5A → #14594C（更深更稳），浅绿底、距离胶囊同步换族
  • 页面底色 #F2F4F6 → #F6F4EF 宣纸米，白卡加暖 88% 半透明不变
  • 六分类色 → 黛蓝 / 苔绿 / 赭石 / 墨青 / 藕紫 / 麦金（同明度低饱和）
  • 地图 Marker 高德蓝 → 主色系 #2F7D68，首屏与品牌一致
  • 状态条棕 / 黄底改深字，消除 3.3:1 的边缘对比
可读性：caption 对比度 2.58 → 3.17:1；主色白字 8.19:1（AA 达标）。
品牌延续改动最小更耐看适合先上

      05 · 怎么落地

      实施成本很低：颜色全部集中在一个文件

      以下为正式实施时的路径（本次未执行任何改动）。

      1. 全部颜色集中在 app/constants/theme.ts：替换 Color 与 CATEGORY_COLORS 两个对象即可全局生效，组件代码零改动（组件全部引用 theme.ts）。
      2. 地图 Marker 与围栏色在 app/app/(tabs)/map.tsx：Marker 改为自定义视图（约 3–5 行），围栏色改 CIRCLE_FILL / CIRCLE_STROKE 两个常量。
      3. 若选方案 C，新增一档 primaryDeep（#0E8A62）：实心按钮 / 绿色小字使用，避免 3:1 边缘对比。
      4. 状态条文字统一改深字（棕 / 黄底），一处样式即可；caption 若想严格达标 AA，可用 #7A7A72 再深一档。
      5. 高德原生地图底图 / POI 颜色无法自定义，品牌表达靠 Marker / 围栏 / 浮层完成——这正是本提案把 Marker 纳入配色的原因。
      说明：本提案是独立 HTML（ui-redesign/index.html），未修改 app/ 目录下任何文件；你随时可以在预览页把四套皮肤来回切换再定方向。
